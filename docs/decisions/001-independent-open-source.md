# Independent open-source repositories

Status: implemented, 2026-10-19.

Schema-v1 contributions reference career projects. Disclosure and tailoring therefore remove them when those projects are withheld or unselected, even when the contribution is independently public.

Schema v2 introduces `openSourceProjects` with repository identity, own/upstream relationship and disclosure; contributions reference these repositories with explicit kind, status and optional URL. IDs remain globally unique. Repository exclusion suppresses children; career-project exclusion does not. Originally rendered grouped repositories in input order with explicit contribution status; the presentation update below supersedes that display rule. Retain independent disclosed records during tailoring; achievement matching remains separate. No contribution scoring.

The v1 reader remains supported. Migration must preserve contribution IDs/attribution and explicitly choose repository permissions and evidenced status; never infer merge/adoption from prose or copy career-project permissions. Publish readers and migration guidance before converting consumer data.

This adds an independent entity but removes a false employment dependency. Reconsider tailoring selection only when actual consumers need to limit this section.

## Presentation update, 2026-10-21

The owner requested shareable CV/profile summaries instead of PR ledgers. Keep typed statuses and evidence in source records, but display delivered contribution summaries without status labels or individual PR lists. Own repositories lead with their descriptions. Unmerged/proposed work and issues are excluded from delivered summaries. This supersedes the original explicit-status display rule; disclosure and independent attribution remain unchanged.
