# Independent open-source repositories

Status: proposed, 2026-10-19; not implemented.

Current contributions reference career projects. Disclosure and tailoring therefore remove them when those projects are withheld or unselected, even when the contribution is independently public.

Introduce schema v2 `openSourceProjects` with repository identity, own/upstream relationship and disclosure; contributions reference these repositories with explicit kind, status and optional URL. IDs remain globally unique. Repository exclusion suppresses children; career-project exclusion does not. Render grouped repositories in input order with explicit contribution status. Retain the disclosed section unchanged during tailoring; achievement matching remains separate. No contribution scoring.

Keep a v1 reader. Migration must preserve contribution IDs/attribution and explicitly choose repository permissions and evidenced status; never infer merge/adoption from prose or copy career-project permissions. Publish readers and migration guidance before converting consumer data.

This adds an independent entity but removes a false employment dependency. Reconsider tailoring selection only when actual consumers need to limit this section.
